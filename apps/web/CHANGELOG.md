# Changelog

All notable changes to `@trainslator/web` are documented here. No tagged
releases yet. Dates are UTC, from the commit history (2026-11-18 .. 2026-11-19).

## Unreleased

### Added

- React 19 + Vite (Rolldown) app with TanStack Router/Query: Playground (`/`)
  — translate against the REST API with WebSocket upgrade when available —
  session login (`/login`), admin console for the languages catalogue and
  translations (`/admin`, `/admin/translations`, `/admin/ai-messages`)
  (`b16b900`).
- Admin pages: keyset-paginated tables, search, create/edit modal,
  soft-delete with confirmation, cache-badge rendering (`b16b900`, `64f383f`).
- AI Studio at `/studio`: per-task forms for the general-purpose AI
  endpoints (sentiment, summarize, QA, NER, zero-shot, embeddings, translate),
  live results, cache badges; falls back to a static registry when the API is
  unreachable (`727acfa`, `225cff9`).
- jsdom + Testing Library coverage for the playground, studio and admin
  components (`.test.tsx`; globally-asserted behavior instead of JSX coverage)
  (`225cff9`).

### Changed

- Extracted shared admin building blocks: `AdminSearch`, `Pagination`,
  `Modal` (`64f383f`); `Modal` is now a native `<dialog open>` element with
  the UA-chrome reset in `styles/styles.css` (`3ec2125`).
- Strict flat-config ESLint stack adopted; JSDoc coverage completed
  (`3ec2125`).
- Prettier wrapping and knip hygiene (`0e5d157`).
- `routeTree.gen.ts` committed and regenerated by the router plugin — never
  hand-edited.
